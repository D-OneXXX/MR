# 真机冒烟清单（v0.17.1，Windows + Linux）

按顺序执行；异常时记录步骤、界面原文、`<数据目录>/logs/app.log` 最后若干行。

> 在线相关步骤优先使用本地回环 stub；真实站点/Telegram 仅在你有权访问时手动验证。
> 应用不自动抓取、不保存第三方 Cookie、不上传书库。

## 准备

- [ ] 准备一本本地 cbz/文件夹（20–60 页）和一本 100+ 页长条漫。
- [ ] 准备一个字典序写入的 20 页 CBZ（`1.png … 20.png`，无前导零）。
- [ ] 设置 → 实验性功能，按需开启「条漫模式」「在线直读」。
- [ ] 记录当前版本：`package.json` 与窗口标题均为 `0.17.1`。

## 常见问题

| 现象 | 处理 |
|---|---|
| 在线解析失败 | 先用「测试」；合法 JSON 语义错误不会回退 HTML；检查在线开关/代理 |
| 在线页 403 | 站点会话失效；填写会话请求头或配对桥接（仅内存） |
| 恢复窗口未出现 | 查看 `logs/app.log` 的 watchdog 记录；确认主窗口未最小化 |
| 更新被拒绝 | 检查公钥、清单签名、sha256、URL 是否 HTTPS/回环 |
