# 真机冒烟清单（v0.14.0）

按顺序执行；异常时记录步骤、界面原文、`<数据目录>/logs/app.log` 最后若干行。

> 在线相关步骤优先使用本地回环 stub；真实站点/Telegram 仅在你有权访问时手动验证。
> 应用不自动抓取、不保存第三方 Cookie、不上传书库。

## 准备

- [ ] 准备一本本地 cbz/文件夹（20–60 页）和一本 100+ 页长条漫。
- [ ] 准备一个字典序写入的 20 页 CBZ（`1.png … 20.png`，无前导零）。
- [ ] 设置 → 实验性功能，按需开启「条漫模式」「在线直读」。
- [ ] 记录当前版本：`package.json` 与窗口标题均为 `0.14.0`。

## 1. 启动与版本

- [ ] `npm run tauri dev` 打开主窗口，无白屏。
- [ ] 任务管理器无 `python` / `python3` / `:8500` 伴随进程；应用启动不拉起 sidecar。
- [ ] 设置 → 关于显示 `v0.14.0` 与构建提交。
- [ ] 故意把 `tauri.conf.json` 版本改错，`npm run build` 应报告精确文件:行；改回后通过。

## 2. 外壳与书库

- [ ] 标题栏可拖动/最大化；导航轨收起与固定展开；`Ctrl+K` 命令中心可用。
- [ ] 状态胶囊显示直连/代理；窗口 900×600 无横向滚动。
- [ ] 书库三栏（导航 + 封面 + Inspector）；窄屏 Inspector 为 Sheet。
- [ ] 搜索、来源筛选、合集/平铺、多选移除/删除正常。
- [ ] 导入文件夹、zip、cbz、中文/空格路径；嵌套两层章节目录也能导入。
- [ ] 字典序写入的 20 页 CBZ 打开后页码严格为 1 → 2 → … → 10 → 11 → 20；
  `1.jpg / 2.png / 10.jpg` 混合扩展名也不乱序。
- [ ] `page_2.png` 排在 `page_10.png` 前；`第2话` 排在 `第10话` 前；前导零与多级目录顺序稳定。

## 常见问题

| 现象 | 处理 |
|---|---|
| 在线解析失败 | 先用「测试」；合法 JSON 语义错误不会回退 HTML；检查在线开关/代理 |
| 在线页 403 | 站点会话失效；填写会话请求头或配对桥接（仅内存） |
| 恢复窗口未出现 | 查看 `logs/app.log` 的 watchdog 记录；确认主窗口未最小化 |
| 更新被拒绝 | 检查公钥、清单签名、sha256、URL 是否 HTTPS/回环 |
