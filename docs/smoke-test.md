# 真机冒烟清单（v0.12.1）

按顺序执行；每步都有“预期”和“异常处理”。哪一步不符合预期，把【上报格式】里的信息发给主控。

> 测试数据：不要用公网漫画站点做自动验收。在线相关步骤使用本地回环 stub（JSON 清单 / HTML 图集），
> 或你自己已登录的站点手动操作；应用不会自动抓取或保存第三方 Cookie。

## 准备

- [ ] **P1 安装 sidecar（仅首次）**：运行 `sidecar\setup.bat` —— 建 `.venv` + 装依赖 + 下载模型到 `sidecar\models\`（约 700 MB）。之后只需 `launch.bat`。
- [ ] **P2 启动 LLM（翻译要用）**：确认 `http://localhost:8080/v1/models` 有响应；并在设置里填写 `trans_model`（默认为空）。
- [ ] **P3 开启实验开关**（按需）：设置 → 实验性功能，分别开启“翻译功能”“条漫模式”“在线直读”。
- [ ] **P4 准备书**：至少一本本地 cbz/文件夹；建议再准备一本 20–60 页的卷做批量测试。

## 1. 启动

- [ ] `sidecar\launch.bat` → 窗口输出 `listening on 127.0.0.1:8500`。
- [ ] 浏览器打开 `http://127.0.0.1:8500/health` → `{"ok":true,...,"models":{"detector":"not_loaded",...}}`（`not_loaded` 正常）。
- [ ] 仓库根目录运行 `npm run tauri dev`，窗口出现，标题栏显示 `MangaReader` 与版本 `v0.12.1`。
- [ ] 若端口被占：`set SIDECAR_PORT=8501` 后重启 sidecar，并在设置页把 Sidecar Endpoint 改成 `http://127.0.0.1:8501`。

- [ ] 拖动标题栏空白处可移动窗口；双击空白处最大化/还原；最小化/最大化/关闭可用。
- [ ] 导航轨收起 48px；鼠标悬停展开 184px（覆盖内容，不推挤）；点「固定展开」后保持展开，刷新后仍保持。
- [ ] `Ctrl+K` 打开命令中心：输入书库中存在的书名 → 结果出现 → Enter 打开；Esc 关闭。

- [ ] Inspector 顶部「详情」右侧有折叠按钮；折叠后变 40px 窄条，再点可展开；刷新后宽度与折叠状态保持。
- [ ] 拖动 Inspector 左边缘可调宽度（约 280–420px）。
- [ ] 页目录默认折叠；展开后只显示前 60 项 + 搜索框 +「加载更多」；点第 50 页 → 阅读器打开并显示 `50 / 总页数`。

- [ ] 「按合集 / 平铺」切换：合集模式下同一系列只显示一张代表卡，角标显示「合集 · N 话」。
- [ ] 导入一个 cbz → 右下角进度卡 → 书库出现新书；拖一个 cbz 到窗口 → 同样导入。
- [ ] 「管理」多选 → 浮动工具条可移除/删除；删除确认里的在线来源**不显示 `?token=` 等 query**。

## 4. 阅读器

- [ ] 单页：左右方向键翻页（RTL 时 ← 为下一页），Space 下一页，Home/End 首末页。
- [ ] `f` 切换单页 → 双页 → 条漫（条漫未开启时跳过）；双页 RTL 封面单独居右。
- [ ] Ctrl+滚轮缩放、拖拽平移、双击重置；页码与进度条同步。
- [ ] 到达末页：在线书若存在下一话，右下出现「本话已读完 / 下一话：…」胶囊；点击切换。
- [ ] HUD：静止 1.5s 后顶部/底部渐隐；移动鼠标、按键、鼠标移到屏幕边缘可唤醒；鼠标停在 HUD 上不隐藏。
- [ ] 打开目录/设置/更多/页签菜单时 HUD 不隐藏；进入选区（`o`）后 HUD 也不隐藏。
- [ ] 页签：打开第 2 本书 → HUD 出现页签切换器（含「书库」）；`Ctrl+1` 回书库，`Ctrl+2` 回到第 1 个阅读页签；`Ctrl+W` 关闭当前阅读页签；中键可关闭页签；「书库」不可关闭。
- [ ] 页签切换后页码恢复；关闭最后一个阅读页签后再开书，进度正确。
- [ ] 选区翻译（需开启翻译 + 配置 LLM）：拖动框选 → 识别 → 翻译 → 结果面板显示；Esc 退出选区。
- [ ] 设置 → 阅读设置里切换 RTL/LTR，翻页方向随之变化。

## 5. 在线直读

- [ ] 书库「URL 直读」→ 弹窗双 Tab：「链接 / 清单导入」「外部浏览器配对」。
- [ ] 单本 JSON 清单 URL：测试 → 仅加入书库 → 书库出现在线书（URL 徽标），可阅读。
- [ ] 多话合集 JSON：粘贴到「多话合集」输入区 → 导入 → 书库按系列聚合；详情里章节选集可切换。
- [ ] 粘贴图片 URL 列表（一行一个）→ 导入成功；标题留空时按 URL 回退命名。
- [ ] 在线开关关闭时：URL 直读入口消失；命令中心的 URL 动作改为「去设置开启」。
- [ ] 配对桥接：Tab 2 →「启动配对监听」→ 状态胶囊显示 `127.0.0.1:<port>`；复制 Callback URL / Pairing Token / 推送模板；在系统浏览器执行脚本 → 应用弹出接收提示，书库角标 +1。
- [ ] 停止监听后端口拒绝连接；再次启动生成新 token。
- [ ] 勾选「允许接收临时请求头至内存」后推送带 `sessionHeaders` 的请求 → 设置页提示“当前使用会话临时请求头”；退出应用后该提示消失（不落库）。
- [ ] 设置页代理旁「获取系统代理」→ 有系统代理时填入输入框并提示“点击保存后生效”；无则提示“未检测到”。保存前数据库不变。
- [ ] 在线提纯：本地 stub 清单含 30 张正文 + Logo/横向 Banner/二维码/头像 → 入库页数为 30；HTML 图集同样只保留 30 张。
- [ ] 打开含尾页推广图的在线章节 → HUD 出现「标记本页为非正文」；标记后当前页移除，过滤抽屉出现 1 条；打开同模板新章节 → 推广图被自动拦截。
- [ ] 过滤抽屉点「恢复为正文」→ 页面插回原位置；再次解析同模板章节不再误杀；设置 → 在线源可看到站点档案/规则统计，并导出/导入/重置成功。
- [ ] Telegram：浏览器地址栏输入公开频道 `https://t.me/s/<channel>` → 出现章节面板（相册/Telegraph/压缩包）；纯文本、头像、贴纸不出现；「加载更多历史章节」可继续翻页。
- [ ] Telegram 单话阅读：打开相册消息 → 可进入单页/双页/条漫；模拟 CDN 403 后重新打开该页 → 后端按 message_id 刷新直链并成功渲染。
- [ ] Telegram 压缩包消息 → 点「下载压缩包」→ 下载到本地 `downloads/telegram` 并进入阅读器。

## 7. AI 流水线

- [ ] 工作台：四下拉框、sidecar 健康行（灰字）；选书 + 页码 → 载入页面 → 开始检测（首次 10–40s，之后秒级）。
- [ ] 框选/删除框 → 执行 → 擦除 + 译文嵌回；原文→译文对照；耗时显示。
- [ ] 同页再次检测 →「缓存秒出」；再次执行 → 命中缓存。
- [ ] 整话批量预翻译：进度条 `N / 总页数 · 成功 X · 失败 Y`；暂停/继续/取消即时生效。
- [ ] 服务状态页：sidecar/翻译健康、调用统计可刷新。
- [ ] 数据页：今日/热力图/趋势/逐书明细与阅读行为一致。

## 常见错误速查

| 现象 | 原因/处理 |
|---|---|
| 健康行红字“sidecar 不可达” | launch.bat 未运行或端口不一致 → 核对设置页 Sidecar Endpoint |
| “系统缺少 ja OCR 语言包” | OCR 选了 Windows 本地 → 换回 mit48px，或安装日语语言包 |
| “翻译请求失败” | LLM（:8080）未启动或 `trans_model` 为空 → 启动 LLM 并在设置中填写模型 |
| 在线解析失败 | 先用“测试”验证；JSON 合法但语义错误不会回退 HTML；检查 `experimental_online` |
| 在线页 403/404 | 站点会话失效；填写请求头或使用配对桥接推送会话头（仅内存） |
| 配对启动失败 | 开关未开、端口绑定失败或已有会话；查看 `get_browser_handoff_status` |
| 浏览器下载未导入 | 仅 zip/cbz 自动导入；确认文件在 `<数据目录>/downloads` |
| 条漫按钮禁用 | `experimentalWebtoon` 未开，或清单缺宽高导致 `webtoonReady=false` |
| 批量任务不动 | `batch_jobs.state` 非 queued；sidecar 健康；查看 `last_error` |
| 磁盘占用过大 | 渲染缓存 2 GiB 自动 trim；可手动删除 `render_cache/` |
