## 已落地对照

| 规范条目 | 实现 |
|---|---|
| 单画布，禁固定三栏 | 三栏壳删除；`App.tsx` 为固定 64px 图标轨（`position:fixed`，hover 展开至 184px，覆盖式不推挤内容）+ 连续画布。**（v3 已推翻：≥1100px 恢复三栏，窄屏 Inspector 变 Sheet）** |
| 图标轨 | lucide 图标 + `.rail-label`，hover 展开文字（300ms `--ease`）；底部主题切换/设置/版本 |
| 书库主页=封面流 | `Library.tsx`：顶部 slim 数据条（`藏书 N · 在读 N · 今日 N 页` mono 小字 + 搜索 + 扫描）+ 封面网格主角；看板组件全部迁出 |
| 完整看板独立"数据"视图 | 新页 `/data`（DataView）：四格统计、Top3、热力图、近14天趋势堆叠（单色蓝系） |
| 详情=浮动 sheet | `DetailSheet.tsx`：右侧滑出（300ms `cubic-bezier(0.22,1,0.36,1)`）+ 半透明遮罩（blur 4px）；遮罩点击/X/Esc 关闭，滑回后卸载；打开期间锁定页面滚动 |
| shared-element 放大 | 封面点击记录 `DOMRect` → 面板落定(330ms)后 ghost 封面 WAAPI FLIP 飞入 sheet 头部(240ms)，落定交棒真图 |
| 封面卡片 | 12px 圆角、封面 3:4 占满、hover 上浮 4px + 阴影加深(150ms) + 底部渐变浮现标题/进度；选中态电光蓝描边 |
| 视图过渡 | 全部路由挂 `.view-fade`（260ms 淡入，含进出阅读器的 crossfade；body 常暗无白闪） |
| 颜色 | 基底 `#0B0B0D`、面板 `#141417`、玻璃 `rgba(255,255,255,0.06)`+blur 12px、电光蓝 `#4D7CFE`（主操作/进度条）；趋势图改蓝系深浅（橙粉紫废弃）；亮色模式保留为次级 |
| 默认深色 | `main.tsx` 一次性迁移（`mr-theme-v2` 标记），Rust/Settings 默认 `dark`；此后用户切换照常持久化 |
| 字体 | 数字/页码/数据 Geist Mono（`.mono`）；中文 Noto Sans SC/雅黑；标题 600–700 |
| 确认对话框 | 新 `ConfirmDialog`（200ms 缩放淡入，Esc=取消），术语表删除接入 |
| 空态/加载/错误 | PixelPet 保留（书架空态、加载中）；每个视图有 hint/toast 兜底 |
| 阅读器 | 真全屏 + 悬浮控制条 3s 自动隐藏（既有）；画布底色统一 #0B0B0D、进度条改电光蓝 |
