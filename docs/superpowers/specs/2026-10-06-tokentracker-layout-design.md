范围：应用壳（左栏导航）+ 书库页（中栏概览 + 右栏详情纵深）+ 新增术语表/服务状态页。阅读器暗色沉浸面**不动**（规范红线）。

## 架构

```
┌─────────┬──────────────────────────┬────────────────────────────┐
│ 左栏rail │ 中栏（概览，2fr）          │ 右栏（详情纵深，3fr）        │
│ ~176px  │ CTA横幅 → 四格统计 → Top3 │ 胶囊时间Tab+刷新 → 超大数字  │
│ 图标+文字│ → 热力图 → 趋势图 → 书架  │ → 渐变进度条 → 分解卡片行    │
│ 分组导航 │ 网格（搜索+封面）          │ → 每日阅读明细表            │
└─────────┴──────────────────────────┴────────────────────────────┘
```

- `App.tsx` 重写为壳：`/reader/:id` 保持全屏沉浸（无 rail）；其余路由 = 左栏 rail + 内容区。
- 书库页内容区两栏 `2fr/3fr`（≈左栏 2 倍/3 倍比例）；<1100px 视口时右栏折到中栏下方。
- 工作台/设置/术语表/服务状态 = 单列内容（居中 max-width 1100），沿用现有页面主体。

## 左栏（功能 = 动词区，不放数据）

- 常规：书库(`/`)、继续阅读(→ 最近更新且有进度的书的 `/reader/:id`，无则禁用)、翻译工作台(`/workbench`)。
- 工具：术语表(`/glossary`，新页)、服务状态(`/status`，新页)。
- 账户：设置(`/settings`)。
- 底部：主题切换（`data-theme` + localStorage + `set_settings` 持久化）、版本小字。

## 中栏（书库看板）

1. **横幅 CTA 卡**（可 dismiss，localStorage 记忆）：继续阅读最近在读的书（标题 + "读到 x/y 页" + 黑色主按钮）。无在读书时隐藏。
2. **四格统计卡**：藏书总数 / 在读 / 今日页数 / **本周页数**。
   - 决策：规范写"本周时长"，但后端无阅读时长数据（`reading_log` 只有按日页数），改用**本周页数**（近 7 天，客户端从热力图数据求和）。如实展示"页/周"。
3. **系列 Top3（按累计阅读页数）**：序号圆徽章 + 书名 + 右对齐加粗百分比（占前三合计已读页数）+ 灰色副标签"已读 x / y 页"。点击 → 右栏选中。数据从 `list_books` 客户端排序（pagesRead = min(currentPage+1, pageCount)），覆盖全部书不受 `dash.series` 的 20 条截断影响。
4. **阅读热力图**：现有 `Heatmap` 组件（GitHub 式周列×日行，绿阶）沿用。
5. **阅读趋势堆叠图**（新 `TrendChart`）：近 14 天按书堆叠的手写 CSS 柱图；Top3 书用规范允许的橙/粉/紫，其余并入"其他"（灰）。首次渲染一次生长动画。
6. **书籍网格**：搜索 + `BookCard` 封面网格（书库本体，属"书籍=中栏"）。点击卡片 = **选中到右栏**（不再是直接进阅读器），双击或右栏"继续阅读"进阅读器；选中态描边高亮。

## 右栏（详情纵深区，选中书籍）

- 未选中/无书：PixelPet 空态提示（三态红线）。
- 顶部：**胶囊时间 Tab**（今天 / 近7天 / 近30天 / 全部 / 自定义[起止日期]）+ 刷新按钮。Tab 只过滤区间数据（分解卡片行、明细表），不过滤书籍事实。
- **超大数字**：已读页数（mono 超粗）+ 单位"页"；灰色说明行"共 N 页 · 剩余 M 页"（对应规范"总页数、已读页、剩余"三件）。
- **渐变总量进度条**：蓝→紫渐变（规范允许的蓝紫渐变仅用于此），含百分比。
- **分解卡片行**：该区间内这本书阅读页数最高的 4 天（日期 + 页数 + 占区间%）。空态提示无记录。
- **每日阅读明细表**：该书逐日页数（日期 / 页数 / 占比），区间内倒序。

## 数据层变更（诚实适配，不造假数据）

`reading_log(date,pages)` 目前是全局按日页数，右栏"选中书籍明细"与"按书堆叠趋势"无法支撑 → 迁移为 `(date, book_id, pages)`：

- `init_schema` 内自动迁移：检测无 `book_id` 列时 rename → 重建 → 旧数据并入 `book_id=''`（全局视图仍聚合，按书视图不含旧史）。
- `set_progress` 按书记账（`ON CONFLICT(date, book_id)` 累加，仍只增不减）。
- `heatmap`/`today_pages` 改 `SUM(...)` 聚合（含旧数据）。
- 新命令：`get_reading_log(bookId|null, days)`（全局或按书逐日）、`get_reading_by_book(days)`（逐日逐书，供堆叠图）。

## 新页面

- **术语表 `/glossary`**：系列（默认书名）+ 原文/译文增删改，走既有 glossary 三命令。Workbench 尚未接入术语表，此页即其正式入口。
- **服务状态 `/status`**：Sidecar 健康（device/models/endpoint）、翻译服务（endpoint + 调用统计）、内存/缓存（get_memory_stats）。手动刷新。全部来自既有命令。

## 视觉 token（theme.css/ui.css）

- 卡片圆角 12→16px，**去描边**（留白+圆角分层），阴影保持极淡；输入框/按钮保留描边。
- 胶囊 Tab（选中态浅灰底）、序号圆徽章、渐变进度条、趋势三色（--trend-1/2/3）、超大数字排版（.hero-num，mono 超粗，单位分离）。
- 主色单屏 ≤2 种；功能色绿=正向/热力图，蓝紫=渐变条，橙粉紫=仅趋势堆叠。
- 动效：Tab/卡片 150ms 淡入（复用 `--transition`/`.fade-in`）；热力图/趋势图首次渲染一次生长动画，之后静止。

## 三态（红线）

每个新组件都有 loading（PixelPet/骨架）、empty（PixelPet+提示）、error（toastErr+内联提示）。沿用现有 PixelPet/Toast 模式。

## 测试

- Rust：迁移（旧表→新表数据保全）、按书记账、全局聚合含旧数据、逐书查询；`cargo test`。
- 前端：`tsc --noEmit`；运行时验收由用户在应用内进行。

## 明确不做（YAGNI）

- 不引入图表库（保持手写 SVG/CSS）。
- 不做阅读时长统计、不做分卷/章节建模（数据模型没有；用"逐日阅读分布"替代"分话卡片行"）。
- 不动阅读器、工作台、设置页的既有布局与逻辑。
